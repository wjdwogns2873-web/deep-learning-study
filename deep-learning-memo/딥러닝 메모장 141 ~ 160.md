model.train()이 실행될 때 뒤에서 벌어지는 일

YOLOv8 내부에서는 백본 신경망이 640 640 사과 이미지를 잘게 쪼개어 수많은 특징을 추출합니다.
이때 Feature Map(특징 맵)과 Anchor Boxes(앵커 박스)가 있다.

YOLO는 이미지를 격자 모양으로 쪼개서 각 칸마다 "여기에 물체가 있나?"를 검사한다.

백본(Backbone)이 하는 일: 이미지 해상도를 점점 줄여가며(640 -> 320 -> 160..) 압축합니다.

Loss 계산: 내부에서는 box_loss, cls_loss, dfl_loss 세 가지의 벌금을 매긴다.

Box Loss: 모델이 예측한 네모 박스가 실제 정답 네모박스와 얼마나 어긋났는지.(주로 CIoU 알고리즘 사용)
Class Loss: 박스 안에 있는 게 사과(0번)가 맞는지, 다른 클래스인지 분류가 틀렸을 때 매기는 벌금(Binary Cross Entropy 사용)

np.frombuffer()는 바이트 버퍼 객체를 메모리 복사 없이 빠르게 1차원 넘파이 배열(ndarray)로 변환해 주는 함수입니다. 데이터를 복사하지 않고 원본 객체의 메모리를 참조하므로 대용량 데이터 처리에 유용하다.

1바이트 크기의 정수형(np.uint8)으로 변환
nparr = np.frombuffer(file_bytes, np.unit8)


cv2.imdecode()는 메모리 버퍼(바이트 배열)에 저장된 이미지 데이터를 디코딩하여 OpenCV의 BGR 이미지 배열(넘파이 배열)로 변환하는 함수입니다.

retval = cv2.imdecode(buf, flags)

buf: 이미지 데이터가 포함된 1차원 넘파이 바이트 배열.

flags: 이미지를 읽어올 방식을 지정하는 옵션입니다.
	cv2.IMREAD_COLOR (기본값): 이미지를 3채널 BGR 컬러로 로드합니다.

model.info()

90,817 parameters (중요)
오리지널 YOLOv8 nano 모델은 파라미터 수가 약 320만개 정도 된다. 그런데 우리가 필요없는 목(Neck)과 머리(Head)의 복잡한 레이어들을 다 쳐내고 초간단 뇌 구조를 만들었더니 파라미터가 9만 개 수준으로 줄었다.

즉, 가볍고 빠른 (하지만 기능은 단순한) 커스텀 YOLO 모델이 탄생했다.


이 실험이 중요한 이유
"작업 환경이 임베디드 장비라 초당 프레임 수(fps)가 너무 안 나와서 모델을 어떻게 경량화 할것인가"
- yaml 파일에서 백본 초입 레이어의 채널 파라미터를 조절하거나 층의 깊이(depth)를 조작하여 파라미터 수와 GFLOPs를 최적화했다.
