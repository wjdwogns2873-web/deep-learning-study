fetch(): 자바스크립트 버전의 RestTemplate

웹 브라우저 환경에서 백엔드 서버로 HTTP 요청을 보내기 위해 사용함.
fetch()를 사용하면 url을 통해 원하는 API의 결과값을 받아올 수 있다.

await: 결과가 올 때까지 잠시 기다려.

만약 await이 없다면, 자바스크립트는 서버에서 Response를 받기도 전에 다음 줄 코드를 실행해 버립니다.

await 키워드는 단독으로 쓸 수 없고, 그 코드를 감싸고 있는 함수 앞에 async가 붙어있어야 합니다.

또한 fetch()가 받아온 response는 HTTP 헤더와 상태 코드 정보만 넘어온 상태이므로 자바 서버에서 받아온 JSON 데이터(body)를 읽어올 때도 await이 한 번 더 필요합니다.
