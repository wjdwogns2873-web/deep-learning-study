const metadata = JSON.stringify({ model_type: selectedModel });

모델명(selectedModel)을 JSON 문자열로 만듭니다.


const metadataBytes = new TextEncoder().encode(metadata);

JSON 문자열을 네트워크 전송용 바이트 배열(Uint8Array)로 변환합니다.
(예: '{"model_type": "FP32"}' -> [123, 34, 109, 111, 100, ...] (22바이트))


const metadataLengthBuf = new ArrayBuffer(4);
new DataView(metadataLengthBuf).setUint32(0, metadataBytes.byteLength, false);

4바이트짜리 빈 메모리 공간(buffer)을 만든 뒤, 거기에 길이(22)를 32비트 정수(setUint32)로 기록합니다. [false = Big-Endian (네트워크 표준 바이트 순서)]


const combineBlob = new Blob([metadataLengthBuf, metadataBytes, blob], 
							 {type: 'application/octet-stream'});

[4바이트 길이 정보] + [JSON 바이트] + [이미지 blob] 3개를 하나의 바이너리 덩어리로 붙입니다.


DataView: 메모리를 다루는 도구/뷰어
빈 메모리에 "몇바이트 단위로 어떤 숫자를 쓸 것인가?"를 지정해서 안전하게 데이터를 읽고 쓰게 해주는 역할.

길이를 같이 보내는 이유??

4바이트는 고정 길이 헤더의 역할을 하고, 백엔드가 무조건 처음 4바이트를 읽어서 메타데이터의 길이(L)를 파악하고
