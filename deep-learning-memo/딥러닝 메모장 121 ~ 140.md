3. Response: 박스가 그려진 프레임을 바이트 데이터로 압축해서 웹 브라우저로 끊임없이 던집니다.

```
iou_threshold=0.45 (Overlap/NMS 필터) 중요

의미: 두 박스가 겹친 영역(IoU)이 0.45 이상으로 너무 많이 겹치면, 둘 중 신뢰도가 낮은 박스는 지워라.

객체 탐지 모델은 사과 하나를 두고도 수십 개의 중복 박스를 치는 버릇이 있다.
이때 두 박스의 교집합/합집합 비율(IoU)을 계산해서 0.45보다 크게 겹치면 더 확실한 박스 하나만 남기고 나머지를 억제한다.


conf 값과 Precision(정밀도), Recall(재현율)의 상관관계

Precision: 모델이 사과라고 친 박스 중 진짜 사과인 비율 (임계값 conf를 높이면 올라감)
Recall: 전체 실제 사과 중 모델이 찾아낸 사과의 비율 (임계값 conf를 낮추면 올라감)
```
