[1] 이미지 분류 (PIL -> PyTorch Tensor 방식)

[파이썬 코드]
contents = await file.read()
pil_image = Image.open(io.BytesIO(contents)).convert('RGB')
image = np.array(pil_image)

파일의 바이트 데이터를 io.BytesIO로 감싸서 메모리상의 가상 파일로 만든 뒤, PIL 라이브러리의 Image.open()으로 읽는다.

albumentations 가공 단계로 넘어가기 위해 데이터를 RGB 채널의 NumPy 배열로 바꾸는 전통적인 파이토치 방식이다.


[2] 객체 탐지 (OpenCV 바이트 디코딩 방식)

[파이썬 코드]
contents = await file.read()
nparr = np.frombuffer(contents, np.uint8)
img = cv2.imdecode(nparr, cv2.IMREAD_COLOR)

파일의 바이트 데이터를 컴퓨터가 바로 읽을 수 있는 부호 없는 8비트 정수 배열로 변환한 뒤, OpenCV의 cv2.imdecode()를 이용해 메모리상에서 바로 이미지 객체로 압축을 풀었다.


[3] 이미지 분류 때 쓰던 방식으로 해도 될까?

[파이썬 코드]
contents = await file.read()
pil_image = Image.open(io.BytesIO(contents)).convert('RGB')
image_rgb = np.array(pil_image)
# YOLO는 BGR 순서를 좋아하니까 BGR로 변환해준다.
img = cv2.cvtColor(image_rgb, cv2.COLOR_RGB2BGR)

result = model(img, conf=0.01)

하지만 OpenCV의 cv2.imdecode() 방식이 메모리를 덜 쓰고 처리속도가 더 빨라서 웹서버(FastAPI)나 실시간 영상 Serving을 할 때는 cv2.imdecode() 방식을 더 선호한다.
