void*는 도대체 무엇인가?
보통 int*는 정수가 들어있는 메모리의 주소, float*은 실수가 들어있는 메모리의 주소.

void*는 타입 정보가 없는 순수한 메모리 주소(만능 주소 포인터)입니다.
void*: 이 주소로 가면 뭐가 들어있는진 몰라도, 그냥 메모리 번지수만 알려줄게.

사용자가 입력으로 float을 넣을지, int를 넣을지 알 수가 없기 때문에
"타입 상관없이 GPU 메모리 주소값만 넘겨받겠다"는 의미.

void* d_input = nullptr;
ㅇ 가리키는 대상이 없어서 void가 아니라, GPU 메모리 주소를 담을 포인터 변수(d_input)를 하나 선언하고, 일단 빈 주소(nullptr)로 초기화.


cudaMalloc(&d_input, inputSize);
ㅇ cudaMalloc은 GPU VRAM에 메모리를 뚫은 뒤에 새로 뚫린 GPU 메모리의 시작 주소를 d_input 변수 안에 write 해주고싶어 합니다.
ㅇ C++ 함수에서 어떤 변수의 값을 바꿔치기하려면 그 변수의 주소(&)를 전달해야 합니다.
ㅇ &d_input은 포인터 변수 d_input의 메모리 주소를 전달해서 cudaMalloc이 내부에 GPU 메모리 주소를 할당하여 채워 넣어주도록 만듭니다.

이 코드가 실행되면 d_input에는 진짜 GPU 메모리의 시작 주소가 담기게 됩니다.


cudaMemcpy(d_input, inputHost.data(), inputSize, cudaMemcpyHostToDevice);
ㅇ d_input: 아까 cudaMalloc으로 얻은 GPU 메모리 주소 (목적지 dst)
ㅇ inputHost.data(): CPU RAM에 올려둔 이미지 데이터의 시작 주소 (출발지 src)
ㅇ inputSize: 복사할 데이터의 용량
ㅇ cudaMemcpyHostToDevice: CPU RAM -> GPU VRAM 방향으로 데이터를 쏜다.

context->executeV2(bindings);
