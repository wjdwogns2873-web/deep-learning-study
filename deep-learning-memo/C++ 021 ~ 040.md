reserve()는 크기를 늘리는 게 아니라, 메모리 공간만 미리 예약하는 것입니다.
ㅇ resize(n): 실제 요소 n개를 새로 생성(크기와 용량 모두 늘어남)
ㅇ reserve(n): n개의 데이터가 들어올 예정이니 힙 메모리에 n개 분량의 자리만 예약하겠다.

이 연산을 하는 이유: std::vector에 데이터를 추가하다가 공간이 부족해지면 메모리를 재할당하고 기존 데이터를 복사하는 연산 발생. reserve()로 미리 메모리를 잡아두면 재할당이 안일어나서 성능이 최적화됨.

emplace_back과 push_back의 차이
ㅇ push_back(val): 이미 만들어진 객체를 가져와서 벡터 공간에 복사하거나 이동
ㅇ emplace_back(args): 객체를 따로 만들어 가져오지 않고, 벡터 내부 메모리 공간에 직접 객체를 즉시 생성

emplace_back은 std::string 객체를 생성해서 복사하는 과정을 생략하고 벡터 내부 공간에서 곧바로 std::string 생성자를 호출하므로 불필요한 메모리 복사가 일어나지 않아 더 빠릅니다.
