CreateTensor할 때 3 * imgSize.at(0) * imgSize.at(1) 대신 blob.size()를 쓰면 안되나?

blob이 어떤 타입인가에 따라 다릅니다.
ㅇ 만약 blob이 std::vector<float>라면:
	ㅇ blob.size()를 쓰면 됩니다.
ㅇ 하지만 float* blob = new float[...] (C 스타일 포인터)라면:
	ㅇ blob은 단순한 메모리 주소(포인터)일 뿐입니다.
	ㅇ 원시 포인터에는 .size()라는 메서드가 없습니다.
```

# 024
```
cv::Mat scores(1, static_cast<int>(this->classes.size()), CV_32FC1, classScores);

메모리 복사 없이, 특정 포인터 주소부터 80개만 1차원 행렬로 즉시 재해석합니다.

ㅇ 1: 행의 개수 1개
ㅇ static_cast<int>(this->classes.size()): 열의 개수 80개
ㅇ CV_32FC1: 데이터 타입 32bit float 채널 1개
ㅇ classScores: 데이터가 시작되는 메모리 포인터 주소

이렇게 처리하는 이유?
80개의 float 메모리를 새로운 std::vector나 cv::Mat으로 복사하면 메모리 할당 비용이 듭니다.


cv::minMaxLoc(scores, 0, &maxClassScore, 0, &class_id);

행렬 내 최솟값과 최댓값, 그리고 그 위치를 찾아주는 함수
cv::minMaxLoc(InputArray src, minVal, maxVal, minLoc, maxLoc)

ㅇ scores: 방금 만든 1 x 80 클래스 점수 행렬
ㅇ 0: 최솟값 저장 변수 포인터-> 관심 없으므로 0 넣음
ㅇ &maxClassScore: 80개의 클래스 점수 중 가장 높은 확률값을 담아올 변수의 주소
ㅇ 0: 최솟값 위치 저장 변수 포인터-> 관심없음
ㅇ &class_id: 가장 높은 확률값의 위치(인덱스)를 담아올 변수의 주소
