1. operator 예약어

기존에 있던 연산자(+, -, ==, new, delete 등)의 동작 방식을 내 입맛대로 커스텀(오버로딩)하는 것입니다.

원래 C++ 표준 라이브러리에는 기본 operator new(size_t size) 함수가 숨어있습니다.
하지만 우리가 void* operator new(size_t size)를 직접 작성하면, 컴파일러는 이 함수를 가져다 씁니다.


2. new를 직접 안 불렀음에도 카운팅이 되는 이유?
C++ 내부에서 힙 메모리를 쓰는 모든 도구들은 결국 맨 밑바닥에서 operator new를 호출하기 때문입니다.
ㅇ std::make_shared<ImageBuffer>()
	ㅇ 스마트 포인터를 만들 때 내부적으로 힙 메모리가 필요하므로, C++ 표준 라이브러리가 내부에서 operator new 를 호출합니다.
	ㅇ 그다음 ImageBuffer 생성자가 실행되면서 안쪽에 있는 data = new float[]가 operator new를 한 번 더 호출합니다.
	
ㅇ std::vector::reserve(), std::queue::push()
	ㅇ vector나 queue같은 STL 컨테이너들도 내부에 데이터를 담을 공간을 확보할 때 operator new를 부릅니다.
ㅇ std::cout
	심지어 std::cout을 처음 실행할 때도 화면 출력용 버퍼 메모리를 잡느라 operator new를 호출합니다.

스택(Stack)이란? "함수가 실행되는 동안만 살아있는 임시 공간"

int main() {
	Box a; // 스택에 Box 하나가 생김
	a.value = 10;
} // main 끝나면 a는 자동으로 사라짐

ㅇ 함수가 시작되면 스택이 쌓이고, 함수가 끝나면 스택이 자동으로 정리됩니다.
ㅇ 그래서 Box a;는 선언만 하면 자동으로 만들어지고, 함수 끝나면 자동으로 사라집니다.
ㅇ 그래서 delete를 쓸 필요가 없습니다. (delete를 쓰면 오히려 에러 발생)
비유: 책상 위에 올려둔 메모지 - 책상 정리할 때 알아서 치워짐


힙(Heap)이란? "프로그래머가 직접 요청해서 만들고, 직접 없애야 하는 공간"

int main() {
	Box* b = new Box; // 힙에 Box 하나가 생김. b는 그 주소를 들고 있음.
	b->value = 20;
	delete b; // 직접 없애야 함
}

ㅇ new Box는 힙에 Box 하나 만들어 달라는 요청입니다.
ㅇ 운영체제가 힙에서 공간을 찾아서 빌려줍니다.
ㅇ delete를 안하면 그 공간은 영원히 빌려진 상태로 남아서 메모리 누수가 발생합니다.
ㅇ 중요한 포인트: b 자체도 스택에 있습니다. b는 "힙에 있는 Box의 주소를 들고 있는 포인터"

스택:                    힙:
┌──────────────┐        ┌──────────────┐
│ a (Box)      │        │ Box          │
│   value: 10  │        │   value: 20  │
├──────────────┤        └──────────────┘
│ b (Box*)     │              ↑
│   0x7f3a...  │──────────────┘
└──────────────┘

b는 8바이트 포인터일 뿐이고, 진짜 Box는 힙에 남아있습니다. 그래서 delete b;를 하면 힙의 Box만 사라지고, 스택의 b는 남습니다. (하지만 가리키는 대상이 없어져서 댕글링 포인터가 됩니다.)

1. if (this == &other)  여기서 &의 의미?
   
&는 여기서 참조가 아니라 주소 연산자입니다.

int x = 10;
int* p = &x; // x의 주소를 p에 저장. 여기서 &는 ~의 주소

&other는 other 객체의 메모리 주소를 의미합니다.
즉, &는 변수 이름 앞에 붙으면 주소, 타입 이름 뒤에 붙으면 참조로 해석됩니다.

2. this에 *를 붙여서 역참조를 하는 이유? MyPointer 객체는 포인터가 아니지 않나?

MyPointer 객체는 포인터가 아니지만, 클래스의 멤버 함수 안에는 this라는 특수한 포인터가 자동으로 생깁니다.
