intersection = (preds * targets).sum()
예측(preds)과 정답(targets)을 곱합니다.
예측은 0~1.0의 실수값이고 정답은 0 아니면 1입니다.
ㅇ 정답이 배경(target = 0)인 픽셀: preds가 어떤 값을 예측해도 0을 곱하니까 0이 됩니다.
ㅇ 정답이 물체(target = 1)인 픽셀: preds * 1 = preds 자기 자신이 됩니다.

즉 (preds * targets).sum()을 구하면 정답이 1인 구역에서 모델이 맞힌 점수들의 총합이 됩니다.

intersection 값이 클수록 모델이 잘 맞혔다는 의미입니다. (완벽하게 맞히면 dice_score는 1이 됩니다.)
