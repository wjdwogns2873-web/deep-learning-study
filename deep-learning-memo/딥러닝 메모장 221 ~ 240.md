self.apply()가 하는 일
"모델 내부의 모든 레이어(자식 모듈)들을 하나씩 순회하면서, 괄호 안에 전달된 함수를 적용해라"

하나하나 레이어를 꺼내서 _init_weights(conv1), _init_weights(bn1)처럼 일일이 호출할 필요 없이, 한 줄로 전체 가중치를 일괄 초기화.

nn.init.kaiming_normal_(m.weight, mode='fan_out', nonlinearity='relu')

활성화 함수로 ReLU를 사용할 때, 가중치를 무작위 난수로 정규분포 초기화하면 층이 깊어질수록 출력값이 0으로 쪼그라들거나(Vanishing Gradient[기울기 소실]) 극단적으로 커지는 현상이 발생합니다.

Kaiming 초기화는 "ReLU를 통과할 때 입력의 분산이 유지되도록" 가중치의 표준편차를 수학적으로 계산하여 적절한 난수로 채워줍니다.

mode='fan_out': 출력 채널의 개수를 기준으로 분산을 맞춘다.(역전파 시 기울기 안정성에 도움)
nonlinearity='relu': 이 레이어 뒤에 ReLU 활성화 함수가 붙는다는 것을 명시하여, ReLU의 특성(음수 제거)에 맞게 초기화 분산을 2배로 보정해 줍니다.

초기화가 필요한 이유:
	가중치 초기값을 전부 0으로 두거나 너무 이상한 값으로 시작하면 모델이 학습을 아예 안하거나 기울기가 폭발/소멸됩니다.
정리하자면, ReLU 특성에 맞춰서 학습이 제일 잘 되는 출발점(초기 가중치 범위)을 맞춰주는거다!
