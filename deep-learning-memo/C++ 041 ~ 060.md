uint32_t 같은 타입을 쓰는 이유: 고정 크기 보장

C++에서 기본 제공하는 int나 long은 컴퓨터 환경(32비트냐 64비트냐, OS는 뭐냐)에 따라 크기가 달라질 수 있습니다. 어떤 환경에서는 int가 2바이트이고, 어떤 환경에서는 4바이트가 되는 식입니다.

ㅇ 어떤 컴퓨터에서 실행하든 무조건 정확히 32비트(4바이트) 양의 정수임을 보장하기 위해 사용합니다.

자주 쓰는 고정 크기 타입 종류
int8_t / uint8_t : 1바이트 정수 / 양의 정수
int16_t / uint16_t : 2바이트 정수 / 양의 정수
int32_t / uint32_t : 4바이트 정수 / 양의 정수 (42억)
int64_t / uint64_t : 8바이트 정수 / 양의 정수


size_t를 쓰는 이유: 메모리 크기와 인덱스 표현의 최적화
ㅇ size_t는 이 컴퓨터에서 표현할 수 있는 가장 큰 객체나 메모리의 크기를 담을 수 있도록 설계된 부호 없는 정수 타입입니다.
ㅇ 용도
	배열이나 데이터의 개수 셀 때(vector.size())
	반복문에서 인덱스(i)를 지정할 때
	메모리 할당 크기 나타낼 때

int는 대부분 4바이트 고정이고 일반적인 산술 계산, 음수가 필요한 수식에서 사용됨
size_t는 컴퓨터 환경(32/64비트)에 따라 자동 변환. 배열 크기, 메모리 크기, 루프 인덱스에서 사용됨


#include <iostream>
#include <vector>
#include <cstdint> // uint32_t, int32_t를 사용하기 위해 필요

// 1. int를 쓰는 경우: 일반적인 계산이나 음수가 필요한 상황
int calcTemperatureDiff(int current, int past) {
	return current - past; // 결과가 음수 될 수 있으니 int 사용
}

// 2. int32_t를 쓰는 경우: 파일 저장이나 네트워크 전송 (크기 고정 필수)
struct PlayerData {
	int32_t hp;  // 어떤 컴퓨터에서든 무조건 4바이트 정수
	int32_t score; // 서버와 클라이언트 간에 데이터 크기가 어긋나면 안됨.
};

int main() {
	std::vector<int> scores = {10, 20, 30, 40, 50};
	
	// 3. size_t를 쓰는 경우: 배열/벡터의 크기나 인덱스
	for (size_t i = 0; i < scores.size(); ++i) {
		std::cout << scores[i] << " ";
	}
	
	return 0;
}

int main(){
	std::vector<int> v = {1, 2, 3};
	int index = -1; // 실수로 인해 음수가 들어갔다고 가정
	
	// v.size()는 size_t 타입임.

	// -1이 size_t로 바뀌면 64비트 기준 18446744073709551615라는 거대한 양수가 됩니다.
	if (index < v.size()) { // -1 < 3 이기 때문에 참이 나와야 하지만..

일반 C++ vs 비동기 웹 프레임워크(Drogon)의 흐름 차이

ㅇ 일반 C++ (절차적 흐름): main() 실행->A 함수 호출->B 함수 호출->프로그램 종료
